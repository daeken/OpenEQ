## Scope and behavior

Classic WLD BSP cells supply exact finite source volumes. Supported `DRNTP`,
`WTNTP`, and `LANTP` reference declarations encode destination zone 255 and the
server zone-point number. Both named declarations and encoded fragment payloads
are read. EQG regions, WLD absolute destinations, and local same-zone asset
teleports remain separate work; no proximity fallback is used.

The collision-resolved player path is swept through the volumes. A new scene
seeds its authoritative arrival position; same-zone teleports rebase that path.
Refused crossings remain latched until backing away, including after server
rewinds. A request uses only an advertised destination, sends the latest player
position before `ZoneChange`, pauses local movement, and waits for the server.
Unknown outcomes time out visibly rather than automatically retrying.

Combat feedback uses server damage amounts and named avoidance codes. It retains
at most 48 events globally/four per target, expires hits after 1.7 seconds and
avoidance after 1.2 seconds, and draws behind ordinary windows. Unrelated fights,
zero-damage buffs and unknown negative codes are excluded. Healing/resist chat
messages are retained; their separate event formats are not yet visualized.

Storage2 now has six dynamic zone workers, increased without restarting active
zones after the live test found the original two-worker pool exhausted. The
additional capacity is persisted as an eqemu.target drop-in.

## Verification record

All 262 workspace tests, including opt-in original-asset and GPU tests, passed.
Strict workspace Clippy and the native debug build passed. Floating annotations
were visually reviewed at normal and Retina scale; reducer checks prove live
Damage ingestion and clearing on zone transition. Subsequent client regression
checks include cancellation/rewind, error timeout and background loading.

The dedicated Mechanic fixture completed a collision-grounded authenticated
round trip. Greater Faydark point 4 was crossed at scene
`[2614.671, -55, 18.84375]`; Crushbone supplied its own spawn at
`[-660, 162, 4.75]`. Walking 13.002 units crossed Crushbone point 1 at
`[-673.0016, 162, 3.0167]`; Greater Faydark supplied the return spawn at
`[2608, -55, 19.25]`. Both handoffs advanced the zone generation, replaced the
server destination table and cleared pending travel; a duplicate request was
rejected locally. Arrival came from the actual spawn, not zeroed success packets.

Mechanic was restored offline to Arena server `[146, -1009, 51]`, heading 0.
Level/stats, HP/mana/endurance, currency and all inventory item contents were
unchanged. Runtime item GUIDs are regenerated by the server and are deliberately
excluded from inventory persistence comparison. Explorer was not logged in or
modified. Reproduce with:

```sh
cargo run -p openeq --bin zone_travel_smoke -- \
  "$HOME/.config/openeq/storage2-gameplay-credentials.json"
```

The probe is restricted to that fixture and records private recovery state
before login. It restores the original position even if a check fails.
